## Featured Projects

### [AI Todo Assistant / RAG Learning Lab](https://github.com/Air000000/fastapi-todo-api/tree/learn-rag)

A FastAPI-based AI application project that combines Todo CRUD, LLM-powered task extraction, and a local-document RAG learning pipeline.

Built features include natural language task extraction, OpenAI-compatible LLM calls, Markdown document loading, chunking, embedding search, Chroma vector store, RAG answers with sources, and retrieval evaluation.

`Python` `FastAPI` `LLM Apps` `RAG` `ChromaDB` `SQLite` `Docker` `DashScope`

### [Codex History Restorer](https://github.com/Air000000/codex-history-restorer)

A local Windows tool for restoring Codex Desktop conversations that still exist on disk but no longer appear in the app.

It supports source discovery, session import, metadata repair, automatic backups, rollback, and a GUI workflow for normal Windows users.

`PowerShell` `WinForms` `SQLite` `JSONL` `Local-first` `Developer Tools`

### [Dev Error Notebook Skill](https://github.com/Air000000/dev-error-notebook-skill)

A reusable engineering memory skill for coding agents.

It helps coding agents turn solved errors into reusable notes, so similar problems can be recognized and handled more consistently in later tasks.

`Agent Workflow` `AI Coding` `Developer Tools` `Knowledge Management`
